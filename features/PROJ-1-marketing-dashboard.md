# PROJ-1: Marketing Agent Dashboard

## Status: In Progress

## Overview
KI-Marketing-Dashboard fuer ein SaaS-Unternehmen, das KI-gestuetzte Loesungen fuer Energieberater im DACH-Raum entwickelt. Das Dashboard bietet einen Ueberblick ueber den Content-Kalender, Kanalplanung und KPI-Tracking.

## User Stories
1. Als Marketing-Manager moechte ich einen Wochenkalender sehen, der alle geplanten Inhalte ueber alle Kanaele zeigt.
2. Als Marketing-Manager moechte ich den Status meiner KPIs (E-Mail-Abonnenten, Demo-Buchungen) verfolgen.
3. Als Marketing-Manager moechte ich den Posting-Rhythmus pro Kanal einsehen.

## Channels & Schedule
- YouTube: Di Tutorial (8-12 Min) + Do Short (60 Sek)
- LinkedIn: Mo Fachartikel, Mi Story-Post, Sa Rueckblick
- TikTok: Mi Quick-Tip, Fr Trend-Format
- Instagram: Do Reel + taegliche Stories
- E-Mail: Welcome-Serie + woechentlicher Newsletter

## KPIs (6 Monate)
- E-Mail-Liste: 2.000+ Abonnenten
- Thought Leadership: KI + Energieberatung
- Demo-Buchungen steigern

## Acceptance Criteria
- [ ] Dashboard page with weekly content calendar
- [ ] Channel cards showing posting rhythm
- [ ] KPI progress indicators
- [ ] Responsive design (mobile + desktop)
- [ ] German language UI
